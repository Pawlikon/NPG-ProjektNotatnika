# NPG-ProjektNotatnika

Projekt aplikacji służącej do obsługi notatek w języku Python, z użyciem biblioteki streamlit.
Aplikacja pozwala na tworzenie notatek oraz przypisywanie im tagów, które mogą być dodawane przez użytkownika oraz na przesyłanie notatek mailem. 
Notatki i tagi zapisywane są lokalnie w formie plików JSON.
